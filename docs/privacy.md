# MusicFree 鸿蒙版隐私政策

生效日期：2026-09-19  
应用名称：MusicFree  
开发者：疯舞小子  
包名：`fun.upup.musicfree.harmony`

本政策适用于 MusicFree 鸿蒙版（含 GitHub 完整版与应用市场本地版）。

## 1. 我们收集哪些信息

本应用不要求注册账号，也不收集你的姓名、手机号、通讯录或听歌记录。

歌单、播放进度、主题和设置仅保存在你的设备上（应用沙箱）。卸载应用后，这些本地数据会被系统清除。

## 2. 权限说明

- **音频播放**：用于播放你导入或已缓存的音频。
- **后台播放**：用于锁屏或切到后台后继续播放。
- **读取本地文件**：仅在你主动选择导入音频或备份文件时访问对应文件，不会在后台扫描整个相册或存储。

你可以在系统设置或应用内「权限管理」中查看相关权限。

## 3. 第三方与网络

本应用不接入广告 SDK，也不接入第三方统计分析 SDK。

- 若你自行填写 WebDAV 地址并使用备份/恢复，备份数据只会发往你指定的服务器。
- 检查更新时，应用可能访问开源仓库以读取版本信息。

应用市场版（`store`）不提供在线搜索、插件音源或网络下载，仅播放你导入的本地音频。

## 4. 插件（仅 GitHub 完整版）

完整版可以安装第三方插件。插件可能向其音源站点发起网络请求，请求内容由插件作者决定。

请自行鉴别第三方插件的安全性。插件产生的数据、隐私与版权问题与本软件无关。

## 5. 未成年人

本应用面向一般用户，不专门面向儿童，也不主动收集未成年人的个人信息。

## 6. 政策更新

政策更新后会在本页面公布。继续使用即表示你了解更新后的内容。
